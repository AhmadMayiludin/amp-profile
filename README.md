# AMP Pedia Company Profile Website

Website company profile modern untuk AMP Pedia.

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Vercel

## Features

- Responsive landing page
- Sticky navbar
- Partner/client logo section
- Services section
- Portfolio filter
- Testimonials carousel
- FAQ accordion
- WhatsApp contact form
- Scroll animation
- Back to top button

## Cara Menjalankan Project

```bash
npm install
npm run dev
```

## Cara Build

```bash
npm run build
```

## Cara Deploy ke Vercel

1. Upload project ke GitHub.
2. Login ke Vercel.
3. Import repository.
4. Pilih framework Vite.
5. Build command: `npm run build`.
6. Output directory: `dist`.
7. Klik Deploy.

## Catatan

Website ini tidak menggunakan database. Semua data disimpan secara statis di file JavaScript.
